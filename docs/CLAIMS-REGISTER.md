# Public claim register

| Claim family | Allowed wording | Evidence class | Prohibited promotion |
|---|---|---|---|
| BRAINK | governed execution/evidence architecture | owner architecture + repository implementation where cited | “proven universally correct”, “zero hallucinations” |
| IL-LLM | local-first semantic/knowledge traversal model | owner architecture + runtime/research artifacts | universal performance claims without workload measurements |
| KEX | addressing/state-geometry mechanics; DNA constraint-source model | owner architecture + qualification artifacts | claiming an address proves semantic truth |
| Immutable ledger | preserves lineage/corrections | architecture + specific replay/integrity tests | “truth is guaranteed by hash/signature” |
| ClaimPath | user-controlled claim evidence/report workflow | product specification + deployed/tested components where read back | insurer acceptance, guaranteed payout, unmeasured savings |
| Runtime performance | exact workload, device, version and observed metric | measured observation | architecture-only speed claim |
| Security | implemented control and tested threat boundary | implementation + test/threat model | “unhackable” |
| Availability | exact deployment and observer scope | public readback | source/build success presented as uptime |

Unsupported claims are rewritten as architecture/proposal or withheld.
