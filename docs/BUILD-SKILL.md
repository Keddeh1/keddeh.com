# Skill: KEDDEH high-calibre public-surface build

1. Resolve source authority before writing copy.
2. State audience, question/task and one primary action.
3. Classify claims: architecture / implemented / local observation / production observation / independent assessment.
4. Design top-down: promise → orientation → mechanism → worked context → evidence boundary → next action.
5. Shared tokens/navigation are a foundation; every route requires specific content.
6. Use progressive disclosure for deep controls; keep high-frequency navigation visible.
7. Implement success, empty, invalid, loading and recoverable failure states.
8. Build from the route registry and fail on unresolved internal destinations.
9. Run DOM audit, runtime tests and secret scan.
10. Record source commit, build digest, deployment identity, canonical-host readback and rollback separately.

Reject fake telemetry, dead links, unlabeled controls, obscured focus, claims beyond evidence, exposed secrets, omitted routes, or runtime edits described as published without readback.
